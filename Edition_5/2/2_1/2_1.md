What is the difference between int, long, long long and short ?

# int

integer
Minimum size 16 bits

# long

long integer
Minimum size 32 bits

# long long

long integer
Minimum size 64 bits

# short

short integer
Minimum size 16 bits

# What is the difference between and unsigned and a signed type ?

An unsigned type represents values from 0 to the upper range. The signed covers both positive and negative values.

# What is the difference between a float and a double ?

A float is a single-precision floating-point and a double is a double-precision floating-point.
