# for loop

When the number of iterations is known in advance.

## pros

- Cleaner
- Control variables are usually declared in the header. Less risc of forgetting updating the counter.

## cons

- Less flexible when the condition is complex, depends on runtime events or is not easily expressed as a simple counter or iterator.

# while loop

When the number of iterations is unknown and depends on a changing condition.

## pros

- Flexible. The loop continues as long as a Boolean condition holds, which can depend on complex state, user input, sensor data, file reading, etc.
- Simple mental model "while this is true, do that."

## cons

- More prone to infinite loops because the programmer is responsible for ensuring the condition eventually becomes false (forgetting to update a variable is a common bug).
- Can be less efficient or harder to optimize in some cases compared with structured counted loops.
- Overuse for simple counted iteration often leads to more verbose and error-prone code than a for loop.
